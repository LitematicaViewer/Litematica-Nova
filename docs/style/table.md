# 表格样式约定

当前 UI 主线是 `desktop-nova`。

## 总体规则

- 表格视觉应遵循 Nova 主题 token。
- 不再沿用旧 PySide6/QTableWidget 主题体系。
- 不再使用历史桌面入口作为表格样式来源。
- 表头、行高、边框、hover、选中态应在 Nova 样式系统中统一处理。

## desktop-nova 表格要求

- 表头固定时不得遮挡内容。
- 行高稳定，hover 不应改变布局。
- 选中态不要过亮。
- 数字列右对齐。
- 名称列左对齐。
- 图标列居中。
- 长文本应省略或换行，不允许挤出容器。

## 材料列表表格

材料列表至少包含：

- 图标
- 名称
- 方块数量
- 容器物品数量
- 合计

导出 CSV 固定三列：

- 名称
- 数字
- 统计数据
