## Beta 0.4.2

**服务公告：渲染服务与镜像下载服务目前暂不可用，预计下周恢复，具体时间以后续公告为准。正式版保留全部受保护渲染核心和远程接口；服务迁移完成后，将通过更新服务器地址并发布后续版本恢复相关服务。GitHub 下载仍可使用。**

### UI 与交互
- 生成投影缩略图时，确认窗、遮罩和底部操作区随主窗口、DPI 与 UI 缩放同步；打开和关闭确认窗不重建原有场景。
- 确认窗打开时可在窗内使用键盘，后台视口不接收输入；关闭内层弹窗不会解除外层弹窗的遮挡。

### Bug 修复
- 修复原生预览遮住缩略图确认窗、排队中的 Esc 误隐藏预览。临时 Fast 截图等到对应帧回执和 PNG 就绪后再交付，随后释放自身会话，不关闭原有交互预览。
- Windows 同目录覆盖安装会识别并清理已停用的官方文件；保留用户修改的文件、投影和备货数据。

### 服务与已知限制
- 本版提供 Windows x64、Linux x64 和 macOS Apple Silicon（ARM64）。不发布 macOS Intel 安装包或更新载荷，历史版本下载不受影响。
- 需要在线领钥的 Standard/Full 新任务在维护期间可能无法启动；不会改用低画质或绕过授权。历史偶发 GPU 崩溃尚未确认全部消除；Standard 个别预加载的显存预算拒绝及 Full 首次进度前的额外等待仍待确认。
- 本轮缩略图已做离屏界面、真实隐藏 HWND 和 Fast 读回验证，未取得 WebView 与 GPU 最终同屏合成图，不代替 Standard/Full 或各平台显卡实机验收。本版 macOS ARM64 包未经过 Apple 公证。
