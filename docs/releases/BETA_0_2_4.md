# Beta 0.2.4

发布日期：2026-10-23

## 更新内容

- 更新标准和完整模式的透明渲染处理，修复原透明捕获状态错误导致的预览退出。
- 修复实体在近距离观察时意外消失的问题。
- 修复完整模式实时缓存恢复时的资源就绪与显示顺序。
- 减少实时预览准备阶段的重复资源读取和解码。
- 修复完整模式光影天空、体积云出现直线切边的问题；该问题已由用户人工验收通过。
- 完善原生预览切页、隐藏恢复、窗口缩放及 DPI 变化处理，防止迟到事件恢复旧视口。
- 修复窗口呈现、安装覆盖升级及更新安装交接，保留现有文件关联和缩略图功能。

## 已知 Bug

- 历史 GPU 偶发崩溃尚未确认全部消除。
- 巨树 Full Vulkan 预加载仍可能耗尽实际显存预算，预检与 Viewer 的预算差异尚未完全收口。
- Linux、macOS 以及不同显卡和场景的图形表现仍需实机反馈；本次人工验收不代表所有平台均已验证。macOS 安装包尚未获得 Apple 公证。
