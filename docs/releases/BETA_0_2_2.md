# Beta 0.2.2

## 更新内容

- 修复完整模式在主窗口预览区没有画面的问题，补齐主窗口与 WebView 同胞窗口的原生裁剪设置；该修复已由用户确认恢复显示。
- 修正完整模式共享光照阶段的准备进度显示，避免正在计算时误显示为停滞或已经完成。
- 修正预览生命周期中的显示、隐藏、任务切换与退出处理，减少旧预览状态影响当前任务的问题。

## 已知 Bug

- 1700W 苦情巨树的完整模式 Vulkan 路径仍出现显存预算不足或分配失败；预算探测与实际 Viewer 运行结果仍有差异，尚未确认消除。
- GPU 偶发崩溃尚未确认消除，相关日志与退出诊断继续保留。
- 部分投影仍可能构建或加载失败；遇到问题可导出日志 ZIP 反馈。
- Linux 与 macOS 尚未完成对应真实桌面及显卡环境的图形功能验收；构建通过不代表实机渲染已验收。
- macOS 安装包未完成 Apple 公证，首次打开可能受到系统拦截。
