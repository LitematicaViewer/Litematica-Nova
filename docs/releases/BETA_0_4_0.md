# Beta 0.4.0

发布日期：2026-10-24

## 更新内容

- 调整左侧主导航，概览、三维、分层、备货、替换和组合/拆分可直接访问，保留原有页面与业务入口。
- 增加可持久保存的多投影组合项目，支持重复实例、显示与锁定、整数平移、直角旋转、镜像，以及合并冲突检查与明确的冲突处理。
- 组合预览接入三维选择和变换操作，支持拆分范围编辑，并按原选区、切割平面或多个 XYZ 范围拆分投影；源文件不因移除组合实例而删除。
- 扩展 Litematica、原版结构及 Create、AnvilCraft、Building Gadgets 格式的识别与数据处理；导出前检查目标格式的实际表达能力，不把不可保留的数据静默丢弃。
- 统一组合、版本转换和导出的数据处理，保留实体、方块实体与附加数据的检查及具体失败原因。
- 更新工作台与设置布局，全局界面缩放支持 0.50×–5.00×，保存所选倍率并同步辅助窗口；整合 Aero7 工具栏贴图调整。
- 保留已有投影库、材料统计、备货任务、世界导出、相机、主题和自动更新功能，提供 Windows、Linux 与 macOS 对应安装及更新包。

## 已知 Bug

- 历史偶发 GPU 崩溃尚未确认全部消除；超大型投影的 Full Vulkan 预加载仍可能遇到实际显存预算不足。
- 部分跨版本实体或附加数据尚不能等价迁移，程序会保留具体原因并阻止有损写出；旧版本特殊方块的显示仍可能存在差异。
- 本次未进行自动 GUI 或实机图形验收，新增组合交互及各平台图形、DPI、安装更新仍需实际使用确认。macOS 安装包尚未获得 Apple 公证，且不支持要求 OpenGL 4.6 的光影包。
