# Litematica-Nova Beta 0.1

## 版本与发布日期
- 实际版本：0.1.1（Beta 0.1 修订版）
- 发布日期：2026-10-13
- 平台：Windows x64；单文件 NSIS Setup.exe 安装包，资源随安装包分发。

## 新增功能
- 属性页和渲染页的独立快速预览，复用原有 Fast 渲染核心；属性页使用主窗口内部的原生子窗口。
- shadcn、8bitcn、Minecraft 三主题，支持浅色、深色及跟随系统。
- Tauri 官方签名自动更新：版本说明、下载进度、取消、跳过版本，以及 GitHub 优先、HTTPS 备用源重试。

## 功能优化
- 统一 SVG 功能图标与单选、勾选控件；游戏材料继续使用真实物品资源。
- 安装包包含快速后端、材料映射、中文语言、物品和方块图标；保留 perMachine 安装方式及 UAC。
- 公开版独立于当前商业完整模式，未提供的功能明确标记。

## 问题修复
- 修复快速预览切换页面后的悬浮残留及异步旧事件重新显示问题。
- 修复大型投影快速网格上传与分块调度导致显示不完整的问题。
- 活塞头、流体等无独立物品的技术状态不再进入材料清单或成本，结构数量保留。
- 补齐公开仓库材料 JSON，修复 Windows CI 干净检出构建及资源打包。

## 已知问题
- 实验性快速模式用于查看结构，不提供完整材质、完整光影；商业 FullMode、V5、Iris 实现未包含在公开版。
- 本轮仅进行 CLI 检查；原生预览画面、DPI、焦点、主题视觉及实际安装/重启流程未进行自动 GUI 或人工视觉验收。
- 部分 Mod 或特殊物品可能缺图；分层绘制工具、格式转换及部分编辑功能仍未完成，请以界面实际状态为准。

## 后续计划
- macOS 和 Linux 将在下个版本支持。
- 根据 Beta 反馈修复 Windows 预览、主题和安装更新问题。
