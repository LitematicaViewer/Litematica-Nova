# Beta 0.2.3

发布日期：2026-10-21

## 更新内容

- 补齐原版实体的模型、外观变体、幼体、姿态及装备附加层，统一标准和完整模式的资源准备与呈现。
- 完善玩家皮肤、披风、鞘翅、展示实体、实体文字、乘客及拴绳的呈现，并更新相关缓存语义。
- 修正共享 Vulkan 透明捕获链的着色器资源绑定、同步及状态初始化缺陷。
- 修复实时缓存恢复时序、缓存读取失败后的收尾及快速模式正常退出误报。
- 修复远程服务文件访问权限导致的标准、完整模式启动时 HTTP 502。

## 已知 Bug

- 历史 GPU 偶发崩溃尚未确认全部消除；部分投影仍可能构建失败。
- 巨型投影 Full Vulkan 预加载仍可能耗尽实际显存预算，预检与 Viewer 的预算差异尚未完全收口。
- Linux、macOS 及不同显卡/驱动的图形呈现未完成全面实机验收；构建成功不代表上述范围均已验收。

- macOS 安装包未完成 Apple 公证，首次打开可能受到系统拦截。
