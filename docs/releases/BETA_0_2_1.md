# Beta 0.2.1

版本：0.2.1  
发布日期：2026-10-16

## 更新内容

- 整合三主题、导航图标、滚动条与投影库界面改进，清理过时提示。
- 调试模式默认关闭，统一管理枚举器与 UI 测试入口；修复辅助窗口关闭职责。
- 统一路径显示与文件身份，保留中文、空格及长路径的正常文件操作。
- 创造模式物品选择按真实物品映射统一名称与图标，并保留方块编辑状态。
- 快速模式的实时与预加载不再等待显存需求预估；标准与完整模式保留原有准入规则。
- 标准与完整模式接入当前视角的方形离屏缩略图。生成、导入、清空与截图统一写入文件内嵌预览，系统缩略入口读取同一来源。
- 补齐旧旗帜、告示牌、容器物品、实体及计划刻的版本迁移，保存前后核对数据；不兼容内容先列出影响，不静默删除。
- 统一 Windows 安装与卸载界面，稳定升级登记并修复历史安装的文件关联与快捷方式。
- 更新检查优先 GitHub，失败再切换镜像；补齐代理继承与实际请求诊断，保持平台对应的更新载荷和签名身份。

## 已知 Bug

- Windows 版本有概率崩溃，尚未确认消除。
- 部分投影无法正常构建，尚未修复。
