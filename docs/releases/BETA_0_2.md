# Beta 0.2 更新日志

版本：0.2.0。发布日期：待发布。

## 更新内容

- 投影库增加父子分类、右键管理和分类图标，保留原有投影文件与分类引用。
- 在线资源接入多个投影来源，完善搜索、下载确认、入库结果及取消操作。
- 材料支持 SVG、TXT、网页和 CSV 导出，可按范围、容器、倍数及末端原料统计。
- 完善快速、标准、完整模式的实时与预加载入口，以及页内原生预览的显示和隐藏生命周期。
- Windows 快速模式增加自动、DirectX 12、Vulkan 选择；标准和完整模式使用 Vulkan。
- 增加最近三次启动会话的日志 ZIP 导出，以及有效显存需求估算的持久复用。
- 完善文件关联、单实例打开队列、共享缩略图与退出处理。
- 修复普通开发分支被启动脚本错误拒绝的问题，支持复用匹配的运行组件。

## 已知 Bug

- Windows 版本仍有概率崩溃，尚未确认消除。
- 部分投影仍可能无法正常构建，尚未修复。
