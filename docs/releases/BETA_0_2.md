# Beta 0.2 本地人工验收

版本：0.2.0（待 Release 构建）。日期：2026-10-13。本轮仅 CLI 自动检查；GPU画面、原生窗口、Explorer 和安装/卸载均未进行自动 GUI / 视觉验收。

## 新增 / 优化 / 修复

- Reden 独立窗口权限、网盘确认、真实 NBT 内容解析及“下载 / 入库 / 广播”结果分离。
- 在线资源来源：RedenMC 保留应用内 API；Minemev、MCodex、Choculaterie、投影工坊、Abfielder、MineSchematic、Shulkr 仅提供真实网站入口，不伪装 API 已接入。详见 [来源说明](../ONLINE_PROJECTION_SOURCES.md)。
- 快速模式接入现有 Viewer 的实际输出纹理读取帧；缩略图按投影内容 SHA256 缓存，投影库与 Explorer 读取同一 PNG。没有缓存时 Explorer 不启动渲染器，也不绘制假投影。
- PNG 临时路径使用独立序号，避免并发串图；缓存保存复核开始时的内容哈希，帧读取结束再次复核源文件状态。Capture 等待使用事件循环的 pending 状态，不重设 Presentation，截图错误与 Viewer 状态错误分离。
- 文件关联 / 单实例请求复用主窗口；关闭时停止接纳任务，后台结束所属子进程，避免在 UI 回调中同步等待。
- 同一次及连续批量打开的每份投影按队列串行入库，仅激活最新投影；实际 React 开文件 effect 的 CLI 数据测试已覆盖此行为。
- Finder 风格父子分类树、右键管理、分类图标与旧标签幂等迁移；多标签引用保留，源目录与投影文件不删除。
- 统计同文件同参数的并发请求共用一次分析：同840FTL基线148.520ms（2进程），修改后125.074ms（1进程）；88534个非空气结构方块、59种真实物品不变。读取、解析、聚合、helper传输均有CLI证据；真实WebView IPC及React提交仍待人工日志。
- 材料可实际导出SVG、TXT、自包含网页及CSV；支持范围、容器、倍数和末端原料。复用配方树，先倍数再批次取整；配方通过显式“准备26.3配方（需联网）”取得，缺失、循环或无法确定的标签明确报错。

## 一次性人工验收清单

### 1. 启动、文件关联与退出

- [ ] 安装后的开始菜单 / 桌面启动入口实际可用；首次启动不会等待后台任务后才画出整个界面。
- [ ] 双击含中文与空格路径的 `.litematic`：启动 Nova 或复用已运行的主窗口，跳转至该投影属性页。
- [ ] 启动加载中连续双击第二份投影、主窗口最小化后再次双击；最终文件正确，实际请求没有丢失。批量路径逐份入库已通过 CLI 数据检查，真实 Explorer 启动 / 跨进程传参仍待人工核对。
- [ ] 预览加载、缩略图生成或文件任务中点击关闭：UI 不长时间失去响应，所属 Viewer / Core 子进程结束，没有遗留窗口；未保存内容与更新安装中的特殊行为另外确认。

### 2. 原生快速预览与真实缩略图

- [ ] 用真实大型投影检查完整模型；旋转、缩放与层选择不改变快速模式身份，不加载 FullMode。
- [ ] 属性 / 渲染页互相切换、离开预览页、最小化与恢复主窗口、移动至不同 DPI 屏幕、弹窗遮挡：HWND 按当前页面和最新容器恢复，没有悬浮或迟到回显。
- [ ] 旋转至明显不同视角后点击“设为缩略图”：PNG 与该次真实帧一致，投影库和 Explorer 同步更新，不是旧缓存、占位图或桌面截图。
- [ ] 截图期间隐藏预览、切换页面、关闭或切换投影：控制及时生效；旧任务不重新显示窗口、不把旧帧写入新投影缓存。
- [ ] 连续 / 并发生成不同投影缩略图，尤其内嵌预览不同的文件：图片不串用；修改源文件后旧内容缓存不冒充新内容。
- [ ] 没有缓存的投影在 Explorer 使用正常文件图标；Explorer 预览本身不启动 Viewer / GPU / Nova。

### 3. 在线资源与窗口主题

- [ ] 以独立窗口打开 Reden，搜索、详情、下载、入库及主题同步实际可用；主窗口刷新收到正确事件。
- [ ] 夸克 / 百度附件及重定向先弹确认：取消不打开、不下载、不入库；确认只打开系统浏览器，不绕过登录。
- [ ] 正常直链入库；登录 HTML、损坏压缩流、普通 NBT 非投影被拒绝，旧文件不被覆盖。
- [ ] 广播故障只出现“已入库但刷新通知失败”；入库失败保留已下载文件位置，不误报网络失败。
- [ ] 其余七站明确显示“仅网页访问”；各确认按钮打开原站，不假称已在应用内搜索 / 下载。投影工坊本次 Web 查询超时，人工检查当前可达性。
- [ ] 三主题浅色 / 深色 / 跟随系统在主窗口、Reden、材料窗口显示一致；键盘、滚动与小窗口布局人工核对。

### 4. 安装 / 卸载归属

- [ ] 安装注册的打开命令正确引用本安装目录，既有其它默认应用选择保持。
- [ ] Explorer 从内容一致的共享 PNG 缓存显示缩略图，DLL 加载 / 卸载不启动 GPU。
- [ ] 升级后另一安装目录的注册项不会被旧卸载器移除；卸载恢复先前缩略图提供器，不删除其它 `.litematic` 用户选择或投影文件。
- [ ] 缓存清理只针对 Nova 自有缓存命名空间；人工确认是否保留用户库、配置和未保存恢复内容。

## 注意事项

分类与导出另行核对：旧标签全部迁移、多引用保留、树操作不删投影文件；SVG/Minecraft/上传图标在三主题明暗与键盘操作下正确；SVG/TXT/网页数量、范围、容器和倍数一致，网页离线可用，末端原料批次取整正确，熔炼燃料另计。记录实际WebView IPC与React Profiler日志，不将CLI传输当作实机渲染。

Windows x64 为当前目标；macOS / Linux 留至后续版本。真实 GPU readback、跨窗口消息、系统文件关联、Explorer COM、关闭时响应与安装/卸载效果尚待上述人工验收。CLI 数据 / 状态测试与编译通过不等于这些项目已经实机通过。
