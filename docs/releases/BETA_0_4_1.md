# Beta 0.4.1

发布日期：2026-10-25

## 更新内容

- 修复多投影备货的投影库选择列表文字重叠：文件名和路径各占一行，长文本省略显示并保留完整提示，勾选框居中，滚动及大倍率布局不再压缩条目。
- 新增多投影合并备货：一次选择多个投影、设置各自建造份数与统计范围，合并等价材料为一张总表；管理来源、显式同步需求时保留总任务的已备数量、备注、存放位置及超额记录。
- 投影库多选可直接加入已有或新建备货任务；增加逐材料需求来源，并兼容旧任务、离线需求快照及完整备份恢复。
- 修复二维分层的版本与资源包选择、模型继承和旋转、特殊模型顶视、透明材质合成，以及低倍缩放和资源切换后的图像缓存恢复。
- 修复快速预览误传资源参数导致的启动失败；保留独立快速模式及编辑场景入口。
- 完善相机拖拽与第一人称飞行输入、鼠标锁定与失焦释放，以及时间天气控制的实际回执；标准模式使用真实无光照配置。
- 缩略图按需读取内嵌图片，三种渲染模式支持截图草稿确认保存；批量生成时保持请求与来源路径一致。
- 修复完整模式地形图集被固定 1 GiB 门槛误拒绝的问题，继续按设备实际能力及显存预算处理。
- 修复侧栏双重滚动，统一辅助窗口的动效偏好，保留三主题与 0.50×–5.00× 界面缩放。

## 已知 Bug

- 历史偶发 GPU 崩溃尚未确认全部消除；超大型投影 Full Vulkan 预加载仍可能遇到实际显存预算不足，预检与 Viewer 预算差异尚未全部收口。
- 部分跨版本实体或附加数据仍不能等价迁移；程序保留具体原因并阻止有损写出，旧版本特殊方块的显示仍可能存在差异。
- macOS 包未获得 Apple 公证，且不支持要求 OpenGL 4.6 的光影包。此次列表离屏验收不等于所有平台、显卡及场景的实机图形验收。
