# Beta 0.3.0

发布日期：2026-10-24

## 更新内容

- 增加简体中文与英文界面，主窗口、辅助窗口及材料导出同步使用所选语言。
- 整合新版投影库，完善分类、搜索、批量管理和文件整理；列表默认显示全部条目。
- 重排统计页与备货工作台，支持独立任务、材料进度、备注和存放位置的持久保存，保留只读材料清单窗口。
- 恢复完整网页导出配置，并统一 SVG、TXT、网页与 CSV 导出；备货任务可导出当前进度或完整备份。
- 加快材料、容器物品、配方及版本查询，减少重复解析与资源读取；修复数据通道偶发断开的问题。
- 默认游戏数据随程序分发，支持从原版 JAR 导入对应版本数据；补齐已登记版本的材料与物品语义，改进跨版本转换的检查与提示。
- 增加三维分层、光影组选项与预设，以及轨道和自由相机。自由相机可选择拖拽观察或鼠标锁定，切页、失焦及 Esc 释放操作状态。
- 增加 Minecraft 虚空世界导出，提供版本选择、后台进度与取消，并保留已有存档的覆盖保护。
- 完善安装升级、语言、资源加载和开发协作入口，保留 Windows、Linux 与 macOS 的原有分发形式。

## 已知 Bug

- 历史偶发 GPU 崩溃尚未确认全部消除；超大型投影的 Full Vulkan 预加载仍可能遇到实际显存预算不足。
- 部分跨版本实体或附加数据尚不能等价迁移，程序会保留具体原因并阻止有损写出；旧版本特殊方块的显示仍可能存在差异。
- Linux、macOS 及不同显卡的图形、DPI 和安装更新仍需实际使用反馈，本次未进行自动 GUI 验收。macOS 安装包尚未获得 Apple 公证，且不支持要求 OpenGL 4.6 的光影包。
