参照外部项目的文档格式编写设计文档：

该项目全名为Litematica Blueprint Assistant，简称Litematica BA，BA还影射一款视频游戏“蔚蓝档案”的首字母。
该项目旨在让用户在不启动游戏的情况下对投影（.litematic）文件进行管理

易混淆专有名词声明：
预览图&缩略图
 - 预览图是文件内的PreviewImageData数组表示的图像
 - 缩略图是由该软件渲染的png图像，也可称之为渲染图


该项目的功能如下：

1.主页（按钮文本为“主页”，非优先）：
目前仅显示一个logo

2.文件管理（按钮文本为“投影库（Schematics Library）”，非优先）：
在指定地点（添加设置项，默认在项目根目录（开发环境）或exe文件同级（生产环境）下的data/schematics/文件夹）存放投影文件并统一管理
 - 以指定的地点作为库的主要根目录以及默认保存位置
 - 可以指定多个文件夹，就像Windows的“库”功能一样
 - 目录下的子文件夹默认全部展开到最里面一层文件（添加设置项，可以设置是全部展开还是全部关闭）
 - 顶部设有功能按钮
   - 重命名
   - 移动到回收站
   - 发送到文件夹（发送到库中其他文件夹）
 - 双击投影（.litematic）文件以激活该文件，告诉其他功能访问该文件，激活前若有已有激活的文件未保存则询问用户是否保存
   - 单击文件也会在文件一行的右侧显示激活按钮
 - 悬浮在文件上时会显示缩略图（若存在）
   - 由于预览图是位于文件内的一串数组表示的（文件为二进制文件，解析需要花时间），在后台异步加载预览图

3.数据读写（按钮文本为“属性（Properties）”，优先）
读写投影文件的头部属性元数据（SNBT格式，需要解析二进制文件）
以下内容针对version=5的文件编写的，更新或更旧的文件可能需要更改格式
 - “选择文件...”按钮（Line.1|一整行的剩余空间）
   - 弹出文件选择UI，用于选择不存在于库中的外部文件，选择文件后直接激活该文件，激活前若有已有激活的文件未保存则询问用户是否保存
   - 在此处激活的文件作为其他功能的活动文件，切换到其他功能时，其他功能所使用的文件就是此处选择的文件
 - “在库中选择...”按钮（Line.1|宽度取决于文字长度）
   - 实际上就是简单地将用户跳转到“投影库”中，让用户自己选择文件激活
 - “文件名称”输入框（Line.2|一整行）
   - 供用户修改文件名
 - 元数据部分（Line.3|左侧部分）
   - “作者”输入框（Line.3L.1）
     - 对应SNBT中的`Author: "string",`
   - “描述”输入框（Line.3L.2）
     - 对应SNBT中的`Description: "",`
   - “时间”文本标签（Line.3L.3）
     - “创建”输入框（Line.3L.3|不可修改）
     - “修改”输入框（Line.3L.3|不可修改）
   - “尺寸”文本标签（Line.3L.4）
     - 对应SNBT中的
```SNBT
EnclosingSize: {
      x: ,
      y: ,
      z: 
    },
```
     - “x”输入框（Line.3L.4|不可修改）
     - “y”输入框（Line.3L.4|不可修改）
     - “z”输入框（Line.3L.4|不可修改）
   - “体积”文本标签（Line.3L.5）
     - “方块数量”输入框（Line.3L.5|不可修改）
       - 对应SNBT中的`TotalBlocks: ,`
     - “体积”输入框（Line.3L.5|不可修改）
       - 对应SNBT中的`TotalVolume: ,`
 - 预览图部分（Line.3|右侧部分）
   - 预览图画布（Line.3R.1）
     - 根据文件SNBT`PreviewImageData:[]`数组的内容显示图片，数组共19600项，图片显示为140x140的倍数
   - 预览图操作按钮（Line.3R.3|居中）
     - “清空”按钮（Line.3R.3|宽度取决于文字长度）
       - 清空该文件的预览图数组
     - “导入”按钮（Line.3R.3|宽度取决于文字长度）
       - 选择一张图片导入，提供一个窗口用户裁剪图片为正方形，随后将其缩放到140x140，用户可以选择采样方式
 - “版本”文本标签（Line.4）
   - “投影文件版本”输入框（Line.4|不可修改）
   - “Minecraft数据版本”输入框（Line.4|不可修改）
 - 区域列表（Line.5）
   - 这是一个列表，表头如下：
     - “区域名称”：区域名称，在SNBT内直接作为类名，即`Regions.区域名`（可修改）
     - “区域尺寸”：占3列表头，子表头分别为xyz，对应SNBT`Regions.区域名.Size.x/y/z`（不可修改）
     - “相对位置”：占3列表头，子表头分别为xyz，对应SNBT`Regions.区域名.Position.x/y/z`（不可修改）
 - 操作按钮组（页脚，靠右）
   - “保存”按钮
   - “另存为”按钮
   - “恢复默认值”按钮
   - “转换格式”按钮（非优先）

4.统计分析（按钮文本为“统计（Statistics）”，次优先）
目前根据旧项目逻辑实现统计逻辑
 - “材料列表”按钮（Line.1|一整行）
   - “材料列表”是一个独立窗口，在下面有写
   - 打开“材料列表”窗口，显示该投影所包含的所有方块材料
 - 统计信息区域（Line.2左侧部分）
   - 按照旧逻辑计算红石偏度、材质、液体偏度、密度
   - 若有缓存，优先展示缓存内容，缓存内容文本为灰色，统计在后台异步进行
 - 统计图表区域（Line.2右侧部分）
   - 若有缓存，优先展示缓存内容，缓存内容文本为灰色，统计在后台异步进行

5.层级展示（按钮文本为“分层（Flake）”，非优先）
目前根据旧项目逻辑实现分层平面渲染
 - 视图区域（界面左侧Line.2）
   - 一个显示视图的区域
   - 若投影拥有多个子区域，则提供下拉框选择显示子区域
 - “显示子区域”下拉框（界面左侧Line.1）
   - 默认显示第一个区域（添加设置项，可以设置是否默认显示全部区域）
     - 因为全区域显示需要重建模型渲染
 - “材料列表”按钮（界面右侧Line.1|一整行）
   - 打开“材料列表”窗口，显示该投影在该层级限制下所包含的方块材料
 - “渲染方案”下拉框（界面右侧Line.2）
   - “遗赠（legacy）”：按照原有代码的方法渲染
 - 层级控制（界面右侧Line.3|左对齐）
   - 一个横向滑动条，包含1个手柄，控制显示层级

6.区域渲染（按钮文本为“渲染（Render）”，非优先）
根据激活的投影文件渲染缩略图，目前根据旧项目逻辑实现整体模型渲染
 - 视图区域（界面左侧Line.2）
   - 一个显示视图的区域
   - 若投影拥有多个子区域，则提供下拉框选择显示子区域
 - “显示子区域”下拉框（界面左侧Line.1）
   - 默认显示第一个区域（添加设置项，可以设置是否默认显示全部区域）
     - 因为全区域显示需要重建模型渲染
 - “材料列表”按钮（界面右侧Line.1|一整行）
   - 打开“材料列表”窗口，显示该投影在选定区域所包含的方块材料
 - “渲染方案”下拉框（界面右侧Line.2）
   - “遗赠（legacy）”：按照原有代码的方法渲染
   - “EndingCredits' Litematic Viewer”：按照`https://github.com/EndingCredits/litematic-viewer`项目的方式渲染
   - “NBT Viewer”：按照`https://github.com/misode/vscode-nbt`项目的方式渲染
 - 方向控制（界面右侧Line.3|居中）
   - 控制视图的方向，共有9个按钮，中间是顶视图，右下左上分别对应东南西北，对角的4个按钮分别对应45角度俯视图
 - 操作按钮组（界面右侧底部|靠右）
   - “写入预览图”
   - “导出缩略图”

7.方块替换（按钮文本为“替换（Replace）”，非优先）
目前根据旧项目逻辑实现方块替换

8.材料列表（独立窗口，优先）
显示投影文件选定区域包含的材料列表
 - 材料列表在选定文件后即刻开始后台异步加载
   - 在加载完成前，若切换了文件，那么没加载完的文件先挂起，等切换后的文件加载完再继续加载
   - 加载完材料列表后写入缓存（位于data/cache）方便之后随时调用
     - 缓存的主键是完整文件路径，文件若在软件不知道的情况下发生改变则缓存失效。
     - 若存在缓存，优先读取缓存内容（即使它已经失效），然后在后台异步加载，缓存内容文本为灰色，加载完成后更新
 - “工作簿”下拉框（Line.1|一整行）
   - 用于切换不同情况下的材料列表，切换工作簿不会导致工作簿清空
     - “整个投影”
     - “选定层级”
     - “选定区域”
     - “自定义文件”（用于直接通过csv打开材料列表）
 - 功能按钮组（Line.1|靠左）
   - “重新加载”：将当前缓存标记为“已失效”，并重新开始从投影文件加载
     - 如果工作簿是“自定义文件”，则该按钮功能改为“浏览材料列表...”
   - “写入文件”：弹出对话框，将该表保存为文件
     - 你想将该材料列表保存为？
     - ASCII艺术表文件（.txt）
     - 逗号分隔值表（.csv）
   - “倍数”输入框：可以上下调节，控制列表正文的材料数量倍数
 - 列表正文
   - 表头如下：
     - “图标”：方块图标（添加一个设置项，决定方块图标以什么方式显示，默认为2D，可切换为3D，首次切换为3D时需要从minecraftwiki下载图标，非优先）
     - “名称”：按照标准译名显示名称，右键点击该行会将表头切换为“方块ID”
     - “总计”：显示统计的数量
   - 鼠标悬浮时显示跟随鼠标的浮窗，内容包括：
     - “项目：”在一行内显示图标和译名名称
     - “ID：”显示方块ID
     - “总计”：显示统计的具体数量
       - 格式为：`总数 " = " 组数 " x 64 + " 余数 " = " 盒数 " 潜影盒 "`
         - 组数 = 总数 / 64（舍弃小数）
         - 余数 = 总数 % 64
         - 盒数 = 总数 / 1728（保留2位小数）
       - 变量数字加粗
       - 添加设置项，决定这些数字是提前算出还是即时演算

9.多语言支持（次优先）
根据json语言文件更改语言
 - 界面语言根据data/lang/中的语言文件显示
 - 游戏标准译名根据data/minecraft/minecraft版本/assets/lang/中的语言文件显示

10.资源管理
管理软件运行所需的资源文件的使用方式，每一个项目提供“加载方式”下拉框，“来源”输入框，“浏览...”按钮（用于快速填写“来源”输入框），“下载/加载”按钮，“删除”按钮
 - 数据值表
   - “从Minecraft Wiki获取表格”：`https://minecraft.wiki/w/Java_Edition_data_values/Blocks`
 - 方块图标（不同方案保存在不同位置`data/minecraft/blockIcon/加载方式`）
   - “从Minecraft Wiki下载png”（Wiki）：暂时未想到解决方案（非优先）
   - “从Vault下载png”（Vault）：从`https://ccvaults.com`下载方块图标的png
   - “从client.jar资产文件构建”（AssetBuild）：读取选定jar文件内`asset/minecraft`内的数据后，根据对应数据值，按照Minecraft Wiki标准视图生成方法渲染图标（非优先）
     - 渲染时视角为45°和60°，且与西北对齐。
     - 图片尺寸为300×300px。无论实际方块的大小如何，都不应对空白部分进行裁剪。
     - 光源的精确值与游戏同步，通过按比例减少三个面的颜色值实现（平行边使用相同的数值）。顶侧：98%，左侧：80%，右侧：60.8%。
     - 禁用抗锯齿，它不适用于游戏中的单个对象。
     - 不要进行后期处理；尤其不要对其进行缩放，因为缩放会使图片应用抗锯齿。如果渲染包含错误，则应该重新进行渲染。
   - “从client.jar资产文件提取2D图片”（AssetUse）：读取选定jar文件内`asset/minecraft`内的数据，直接提取出来使用（非优先）
   - “使用已有资产库构建”：构建方法见上，但是读取的是asset文件夹，文件夹可以是网络来源（非优先）
   - “使用已有的图片”（Local）：选定包含图片的文件夹，直接使用里面的图片
 - 物品图标 （不同方案保存在不同位置`data/minecraft/itemIcon/加载方式`）
   - “从Minecraft Wiki下载png”（Wiki）：暂时未想到解决方案（非优先）
   - “从Vault下载png”（Vault）：从`https://ccvaults.com`下载物品图标的png
   - “从client.jar资产文件提取2D图片”（AssetUse）：读取选定jar文件内`asset/minecraft`内的数据，直接提取出来使用
   - “使用已有的图片”（Local）：选定包含图片的文件夹，直接使用里面的图片
 - 语言文件
   - “从Minecraft Wiki获取”：暂时未想到解决方案，放个占位
   - “从外部文件获取”：读取选定json文件，并提取方块和物品译名，如果文件名不是语言代码，则询问用户该文件属于哪个语言
     - 默认从`https://github.com/InventivetalentDev/minecraft-assets/blob/$版本$/assets/minecraft/lang/$语言$.json`获取
       - $版本$从设置中读取，目前是26.1
       - $语言$根据设置中的显示语言而定，默认为系统语言
