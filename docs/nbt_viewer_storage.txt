NBT Viewer 资源说明
===================

当前主线是 desktop-nova，旧 PySide6/NBT Viewer WebView 方案不再是运行主线。

保留本文只用于说明历史资源分层：

1. 随 Minecraft 数据版本变化的资源应放在用户数据目录，不应提交到 Git。
2. UI 自定义代码不应直接混入上游 viewer 打包产物。
3. 如果未来重新接入 Web NBT Viewer，应把上游资源、用户资源和本项目覆盖层分开。

建议目录：

- 项目内：只放固定启动模板和本项目覆盖层。
- 用户数据目录：放 Minecraft 版本资源、atlas、mcmeta 等可下载/可更新内容。
- 生成缓存：放合并后的临时 html 或资源索引。

当前 desktop-nova 不依赖本文描述的旧 PySide6 路径。
