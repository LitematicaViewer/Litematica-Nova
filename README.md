# Litematica-Nova

**不用进入游戏，也能整理投影、查看材料、按层施工。**

面向 Minecraft 玩家的 Windows、Linux 和 macOS 桌面工具。打开 `.litematic` 文件，就能查看投影信息和材料清单，也可以修改属性、批量替换方块，或从模板生成一份新投影。

## 为准备材料和施工而设计

- **材料一目了然**：主要材料用图标、中文名称和数量组成清爽列表，支持按区域、按层查看及导出 SVG / TXT / 网页 / CSV；可选择统计容器内物品。
- **按自己的习惯计数**：材料可用「箱盒－盒－组－个」或直接数量显示，不用重新分析文件。
- **逐层看清结构**：拖动、缩放、切换层级，用下层半透明参考辅助定位；查看箱子、潜影盒、木桶和漏斗内容。
- **先看影响，再保存**：替换方块和模板生成均可先预览；属性编辑支持另存为。
- **集中管理投影**：左侧使用父子分类树，中间查看预览卡片，右侧查看详情；支持右键管理、搜索、批量选择和拖动归类，旧标签会迁移为分类。在线资源入口包含 RedenMC 与多家原站。没有预览图时显示占位，不使用其他图片冒充。
- **三种外观，操作不变**：shadcn/ui 现代简洁，8bitcn/ui 精致像素，Minecraft 保留游戏字体与纹理风格。三主题都支持**浅色、深色、跟随系统**；选择会保存，主窗口和辅助窗口同步更新。
- **属性与预览放在一起**：属性页与渲染页支持快速、标准和完整模式；当前视角可设为文件缩略图。生成、导入与清空预览统一写入投影文件，复制或改名后仍随文件保留。

## 开始使用

各平台下载与版本以 [Releases](https://github.com/LitematicaViewer/Litematica-Nova/releases) 中实际提供的安装包为准。


1. 从 [Releases](https://github.com/LitematicaViewer/Litematica-Nova/releases) 下载对应平台和架构的安装包；所需资源随程序分发。Windows x64 使用单文件 `Setup.exe`，安装到所有用户，需要确认 UAC。Linux 使用 `.deb` 或 `.AppImage`；macOS 分别提供 Intel x64 和 Apple Silicon arm64 的 `.dmg`。
2. 点击「打开投影文件」，选择自己的 `.litematic`。它是独立软件，**不需要放进游戏的 mods 文件夹**。
3. 在左侧切换统计、材料、分层等页面。首次尝试修改时，请保留原件，选择「另存为」。

Linux 需要 glibc 2.39 或更新版本、GTK 3、WebKitGTK 4.1、系统 Vulkan loader（Debian/Ubuntu 通常为 `libvulkan1`）及正常显卡驱动；AppImage 不包含显卡驱动。Wayland 桌面通过 XWayland 运行原生嵌入视口。macOS 需要 13.0 或更新版本；安装包尚未获得 Apple 公证，系统可能提示确认来源。其它投影格式尚未作为正式发行功能提供。

## 开发路线图

以下为尚未全部完成的功能方向；实际已交付内容以更新日志和发行包为准。

### 下一阶段（计划）

- **多平台兼容性完善**：根据 Windows、Linux 和 macOS 的实机反馈，继续完善驱动兼容、窗口、文件关联与安装更新。
- **扩充投影下载源**：接入更多投影分享/整合网站，支持从网站提供的网盘分享链接下载并导入投影。
- **完善双击打开投影**：继续完善 `.litematic` 文件关联及不同桌面的打开行为。
- **完善投影库**：补全文件夹分类、标签、搜索筛选及投影整理等管理能力。
- **文件管理器缩略图**：在系统文件夹内直接预览投影缩略图，作为文件关联功能的延伸；按操作系统分别适配（优先 Windows 资源管理器）。

### 后续版本（规划中）

- **导出为 Minecraft 世界**：将投影方块生成可加载的世界存档，**默认采用虚空世界背景**。
- **更多投影格式**：在 `.litematic` 之外，支持原版结构方块的 `.nbt`、机械动力及铁砧工艺相关结构格式，以及「复制粘贴小帮手」使用的格式。
- **模组方块替换**：支持导入模组并将方块替换为模组内方块。
- **投影组合与拆分**：同时打开多个投影，按相对位置装配成大型投影；也可以将大型投影拆分为多个独立部件。
- **末端原材料统计**：将建造材料进一步换算为基础原料，例如原木、铁锭等，复用现有网页端的计算能力。
- **3D 分层查看**：在三维视口中按高度或选定范围逐层检查结构。
- **无光照完整渲染**：在完整渲染基础上提供关闭光照影响的显示模式，便于辨认结构细节。
- **完整渲染中的方块修改**：直接在三维完整渲染视口内选择、修改方块。
- **独立投影工作台**：开发类似 Axiom 操作体验的外置投影编辑工作台，支持可视化构建与编辑。


### 使用前需要知道

- 属性页使用独立快速渲染，支持实时与预加载，适合查看形体；它与标准、完整模式独立，不承诺完整材质或光影效果。预览显示在应用内部，切页、隐藏与恢复时复用当前场景。小窗口、DPI 缩放、弹窗遮挡和窗口切换仍需统一人工确认。
- Windows 快速模式可自动选择 DirectX 12 / Vulkan，也可手动指定；Linux 使用 Vulkan，macOS 快速模式使用 Metal，标准和完整模式使用 MoltenVK。macOS 暂不支持要求 OpenGL 4.6 的 Iris 光影包。标准和完整模式不会以快速模式代替。
- 二维分层是施工参考，不是游戏画面。缺少地图基色时，缩小显示会使用区分色；部分 Mod 方块或状态可能缺图。
- 分层页面的保存只写入**原点修改**。测量、快捷栏与调试棒状态草稿仅在当前会话生效；灰色绘制工具仍是占位。
- 材料以原版 26.3 的实际物品映射为依据；活塞头、流体等没有独立物品的状态只计入结构与单独说明，不伪造物品或重复计料。特殊方块、Mod 内容和自定义物品组件需留意提示，不保证代表生存模式中的全部获取成本。
- 已提供 1643 个静态物品图标，覆盖原版可放置材料对应的全部 1141 种物品。另有 14 种非放置物品的默认着色、组件或场景图标暂未覆盖，仍用问号占位。图标不展示自定义头颅皮肤、附魔动画或季节变化；无直接对应物品的技术方块会单独标注。
- AI 辅助需要额外配置服务、模型及密钥，可能产生费用；Gemini 入口尚未接入。在线投影库依赖网络及第三方服务。

## 调试入口

「UI 测试」与「枚举器」默认隐藏；需要时可在选项中启用「调试模式」，关闭后相应窗口退出。普通统计、替换与分层功能不受影响。

## 更新程序

启动后会在后台检查更新。有新版本时显示版本、日期及新增/优化/修复/注意事项；可以更新、取消，或跳过当前版本。确认更新后显示下载进度，使用签名校验，保存当前草稿并等待后台写任务退出，再安装重启。GitHub 接口失败时切换专用 HTTPS 镜像。

更新源使用 GitHub HTTPS 清单及专用 HTTPS 镜像。Windows 下载签名 NSIS 安装包，Linux 按安装形式使用签名 AppImage 或 Debian 安装包，macOS 使用对应架构的签名应用更新归档；同平台主源和镜像提供相同版本与签名。实际安装与重启仍需用户实机反馈；具体配置见 [更新维护说明](docs/UPDATER.md)。
