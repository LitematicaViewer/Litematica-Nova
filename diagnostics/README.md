## Status

Generated diagnostic output.

## Maintenance note

- Diagnostic bundles are generated by `python scripts\export_diagnostics.py`.
- Bundle directories use the format `bundle_YYYYMMDD_HHMMSS`.
- Bundles are safe to delete when they are no longer needed for an investigation.
- Do not store API keys, tokens, cookies, full user `.litematic` files, or large cache binaries here.

## Reading guide

See `docs/DIAGNOSTICS.md` for the meaning of each generated file and which file to inspect for AI plan, preview, native viewer, cache, blockstate, or projection library issues.
