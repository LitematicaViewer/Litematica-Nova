## 影片目标与形式

面向 Minecraft 建筑玩家：无需启动 Minecraft，先整理投影、看结构，再把材料与施工进度带走。两条独立本地化成片，各 120 秒 / 1920×1080 / 60fps / H.264 + AAC。无旁白，原创配乐和 SFX 与双语字幕承载节奏。对应 `recording-script.md` 是字幕/可选录音稿，不假称已录音。

## 视觉与运动

- 专业桌面工具 + 工程蓝图 → 实体建筑；深冷灰、白、低饱和蓝。
- 产品 shadcn 深色真实 tokens：背景 #141416、卡片 #1c1c1f、边框 #3b3b42、前景 #f4f4f5、次要文字 #b1b1bb、6px 圆角。
- 字体 Segoe UI / Microsoft YaHei UI；本机已验证可用。电影主标题 43–77px，产品演示控件约18–30px，安全区左右≥96px。
- 产品 UI 取公开 Tag 的导航、按钮、表格、布局及标识；视频组件是独立的可重复状态演出，常驻“发布界面演示 · 演示数据”标识，不冒充应用截图。
- 真实 GPU 内容仅使用资产清单已确认的原始帧；二维分层明确标为真实 Core 数据视图，不把任意裁图冒充三维切层。
- 六个运动语法：单主体 Hero 聚焦、蓝图遮罩、卡片错峰归位、光标先导、行嵌入/数量后果、UI边缘收束/CTA。无手持抖动、无随机粒子、无白闪过场。
- 主要缓动 bezier(.22,1,.36,1)，光标先于结果，40帧左右完成点击，结果至少保持36帧。18–36帧入场，静止结果与快速镜头交错；不把所有控件套弹簧。
